# 🤖 AI Chatbot using Ollama + Streamlit

A simple conversational AI chatbot built using Python, Streamlit, and Ollama.

## 🚀 Features

- 💬 Chat interface using Streamlit
- 🧠 Local AI model using Ollama
- 💾 Conversation history using Streamlit Session State
- ⚡ Real-time AI responses
- 🔒 Runs locally without exposing conversations to an external API

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- LLM
- Session State
